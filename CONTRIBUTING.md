# Contributing

## Setup

```sh
dart pub get
```

## Checks

```sh
dart format .
dart analyze
dart test
dart doc
```

Single test:

```sh
dart test test/core/service_container_test.dart
```

## Pull requests

- Keep `lib/src/core` and `lib/src/layout` nocterm-free.
- Add or update tests for behavior changes (TDD preferred).
- Update `CHANGELOG.md` for user-facing changes.
- Do not hand-edit `doc/api` (generated by `dart doc`).
